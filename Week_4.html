Week 4

CSS Basics

In this week we will cover the basics of CSS. CSS is used to style and layout web pages. It allows you to apply styles to HTML elements, such as colors, fonts, and spacing.

We will also cover the different types of CSS, including inline, internal, and external CSS. By the end of this week, you should have a good understanding of how to use CSS to enhance the appearance of your web pages.

Inline CSS

Inline CSS is used to apply styles directly to an HTML element using the style attribute. This method is not recommended for large projects as it can make the code harder to maintain.
