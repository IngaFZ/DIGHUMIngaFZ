Generic characters

In this task, you will learn about generic characters in HTML. Generic characters are used to represent special characters that have a specific meaning in HTML.

div tag

The <div> tag is a generic container for flow content. It has no effect on the content or layout until styled using CSS. It is often used to group elements for styling purposes (using the class or id attributes), or because they share attribute values, such as lang.

span tag

The <span> tag is an inline container used to mark up a part of a text, or a part of a document.

Escape characters

In this task, you will add navigation links to your HTML page. Here is the most popular escape character: &

  • Use > for the greater-than symbol (>)
  • Use " for the quotation mark (")
  • Use ' for the apostrophe (')
